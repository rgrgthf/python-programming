# Python 运算符优先级 —— 学习笔记

## 一、运算符优先级总表（从高到低）

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最高） | `**` | 幂运算 |
| 2 | `~` `+` `-`（一元） | 按位取反、正号、负号 |
| 3 | `*` `/` `//` `%` | 乘、除、整除、取余 |
| 4 | `+` `-`（二元） | 加、减 |
| 5 | `<<` `>>` | 左移位、右移位 |
| 6 | `&` | 按位与 |
| 7 | `^` | 按位异或 |
| 8 | `|` | 按位或 |
| 9 | `==` `!=` `>` `<` `>=` `<=` `is` `in` | 比较运算符 |
| 10 | `not` | 逻辑非 |
| 11 | `and` | 逻辑与 |
| 12（最低） | `or` | 逻辑或 |

> 口诀：**幂 → 一元 → 乘除 → 加减 → 移位 → 位运算 → 比较 → 逻辑**

---

## 二、重点详解：`~` 按位取反（你看不懂的）

### 2.1 基本概念
`~` 是把一个整数的**二进制每一位**都翻转：0 变 1，1 变 0。

### 2.2 为什么 `~12` 等于 `-13`？

Python 使用**补码（two's complement）**来表示负数。规律很简单：

$$
\boxed{\ \tilde{\ }n = -n - 1\ }
$$

| n | ~n | 验证 |
|---|-----|------|
| 12 | -13 | -12 - 1 = -13 ✓ |
| 8 | -9 | -8 - 1 = -9 ✓ |
| 0 | -1 | -0 - 1 = -1 ✓ |
| -5 | 4 | -(-5) - 1 = 4 ✓ |

### 2.3 图解（以 8 位为例）

```
 12 的二进制： 0 0 0 0   1 1 0 0
  ↓ 逐位翻转
~12 的二进制： 1 1 1 1   0 0 1 1
               ↑最高位是1 → 表示这是一个负数
  ↓ 按补码解读
~12 = -13
```

> **一句话**：`~n` 就是 `-n - 1`，记住这个公式就够了！

## 三、重点详解：一元 `+` 和 `-`（你也看不懂的）

### 3.1 一元 vs 二元

`+` 和 `-` 有两种身份：

| 身份 | 例子 | 含义 | 优先级 |
|------|------|------|--------|
| **一元**（单目） | `-5`、`+3` | 正负号 | **高**（优先级 2） |
| **二元**（双目） | `5 - 3`、`2 + 3` | 加减运算 | **低**（优先级 4） |

### 3.2 具体含义

```python
-5    # 一元负号：把 5 变成 -5（取相反数）
+5    # 一元正号：保持 5 不变（几乎不用）
5 - 3 # 二元减号：5 减去 3 = 2
5 + 3 # 二元加号：5 加上 3 = 8
```

### 3.3 优先级差异示例

```python
-3 ** 2      # = -9，因为 ** 优先级最高，等价于 -(3**2)
(-3) ** 2    # = 9，括号改变了优先级

-5 + 3       # = -2，一元 - 先作用于 5，再 +3
-(5 + 3)     # = -8，括号改变顺序

~-5          # = 4，一元 - 优先：~(-5) = -(-5) - 1 = 4
```

## 四、`~`、一元 `-`、一元 `+` 之间的优先级

它们三个**优先级相同**，都是优先级 2。结合方向是**从右到左**：

```python
~-5     # 先算 -5 = -5，再算 ~(-5) = 4
-~5     # 先算 ~5 = -6，再算 -(-6) = 6
```

## 五、🔥 一条龙示例：一个表达式涵盖全部 12 级优先级

下面这个表达式**从最高优先级到最低优先级**，每一步都标注了当前由哪个运算符驱动：

```python
result = ~-2 ** 3 + 4 * 5 // 6 % 7 - 8 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

### 逐步拆解（Python 实际运算顺序）

```
原始表达式:
~-2 ** 3 + 4 * 5 // 6 % 7 - 8 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

---

**① `**`（幂运算，优先级最高）**

```
2 ** 3  →  8
→  ~-8 + 4 * 5 // 6 % 7 - 8 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

**② `~`、一元 `-`（优先级 2，从右向左）**

```
先算一元 -：  -8 = -8
再算 ~：      ~(-8) = 7    （公式：~n = -n-1，所以 ~(-8) = 8-1 = 7）
→  7 + 4 * 5 // 6 % 7 - 8 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

**③ `*`、`//`、`%`（优先级 3，从左向右）**

```
4 * 5    → 20
20 // 6  → 3
3 % 7    → 3
→  7 + 3 - 8 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

**④ `+`、`-`（二元加减，优先级 4，从左向右）**

```
7 + 3  → 10
10 - 8 → 2
→  2 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

**⑤ `<<`、`>>`（移位，优先级 5，从左向右）**

```
2 << 1  → 4     （10 左移 1 位 → 100，即 4）
4 >> 2  → 1     （100 右移 2 位 → 1，即 1）
→  1 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

**⑥ `&`（按位与，优先级 6）**

```
1 & 3  → 1     （二进制：01 & 11 = 01）
→  1 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
```

**⑦ `^`（按位异或，优先级 7）**

```
1 ^ 4  → 5     （二进制：001 ^ 100 = 101）
→  5 | 5 == 6 and not 7 > 8 or 9 < 10
```

**⑧ `|`（按位或，优先级 8）**

```
5 | 5  → 5     （二进制：101 | 101 = 101）
→  5 == 6 and not 7 > 8 or 9 < 10
```

**⑨ `==`、`>`、`<`（比较运算，优先级 9）**

```
5 == 6  → False
7 > 8   → False
9 < 10  → True
→  False and not False or True
```

**⑩ `not`（逻辑非，优先级 10）**

```
not False  → True
→  False and True or True
```

**⑪ `and`（逻辑与，优先级 11）**

```
False and True  → False
→  False or True
```

**⑫ `or`（逻辑或，优先级 12，最低）**

```
False or True  → True    ← 最终结果！
```

### 🎯 验证

```python
>>> result = ~-2 ** 3 + 4 * 5 // 6 % 7 - 8 << 1 >> 2 & 3 ^ 4 | 5 == 6 and not 7 > 8 or 9 < 10
>>> print(result)
True
```

## 六、示例二：比较 + 逻辑专项（含 `is`、`in`、`!=` 等）

```python
result = 3 * 4 >= 10 != 11 and "a" in "abc" is True or not 7 <= 3
```

### 逐步拆解

**① `*`**：`3 * 4` → `12`

**② 比较链**：Python 中 `12 >= 10 != 11` 等价于 `12 >= 10 and 10 != 11` → `True and True` → `True`

**③ `in`**：`"a" in "abc"` → `True`

**④ `is`**：`True is True` → `True`（注意 `is` 比 `and` 优先级高）

**⑤ `<=`**：`7 <= 3` → `False`

现在的样子：`True and True or not False`

**⑥ `not`**：`not False` → `True`

**⑦ `and`**：`True and True` → `True`

**⑧ `or`**：`True or True` → **`True`**

## 八、速查口诀

1. **`~n` = `-n - 1`** ← 按位取反就记这个
2. **一元先于二元** ← `-5+3` 是 `(-5)+3`，不是 `-(5+3)`
3. **完整口诀**：**幂 → 一元 → 乘除 → 加减 → 移位 → 按位与 → 按位异或 → 按位或 → 比较 → not → and → or**
