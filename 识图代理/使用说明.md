# 识图代理 — 给 Copilot 装上"眼睛" 👀

## 这是什么

Copilot Chat 自带的识图很慢（要 1-2 分钟）。这个代理用**免费**的多模态模型
（智谱 GLM-4V-Flash）来做识图，速度快得多。

原理：`server.py` 是一个 MCP 服务器，VS Code 启动它之后，Copilot 就能直接调用
里面的 `describe_image` 工具——你在聊天里发图片路径，它调用免费视觉模型识图，
把文字结果返回给 Copilot，全程自动、无缝。

## 第一次配置（只需要做一次）

### 1. 注册智谱 API Key（免费）

1. 打开 https://open.bigmodel.cn
2. 用手机号注册登录
3. 左侧菜单找「API Keys」→ 创建新的 API Key（格式类似 `xxxxxxxx.xxxx`）
4. 复制这个 Key

### 2. 填入 config.json

1. 把同目录的 `config.example.json` 复制一份，改名为 `config.json`
2. 打开 `config.json`，把 `api_key` 那一行换成你的 Key
   ```json
   {
     "api_key": "你的Key粘贴到这里",
     "model": "glm-4v-flash",
     "base_url": "https://open.bigmodel.cn/api/paas/v4/chat/completions"
   }
   ```
3. 保存

> GLM-4V-Flash 是免费模型，不限量，放心用。

### 3. 重载窗口

VS Code 里按 `Ctrl+Shift+P` → 输入 `Reload Window` → 回车。
MCP 服务会自动启动（.vscode/mcp.json 已配置好）。

## 日常怎么用

在 Copilot Chat 里直接对我说：

- 「帮我看一下这张图：`C:\...\图片.png`」→ 我会调用识图工具
- 「这张图里有什么药：`xxx.jpg`」→ 我会带着你的问题去识图
- 不确定路径？说「列出 `C:\...\文件夹` 里的图片」→ 我用 list_images 帮你找

> 提示：图片要是**工作区里的文件路径**才能被读到（比如放在
> `Python药学学习体系\学习记录表\学习记录表附件\` 下面）。

## 常见问题

- **「未配置 API Key」**：config.json 没填好，或改完没重载窗口
- **「找不到图片文件」**：路径写错了，先用 list_images 确认
- **「图片太大」**：超过 10MB 会拒绝，压缩一下再试
- **想换模型**：config.json 里改 model 和 base_url 即可（免费就先用 glm-4v-flash）
