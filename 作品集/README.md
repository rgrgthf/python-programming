# 作品集 Portfolio

> 这是你学习成果的展示区 —— 考研复试、找实习、向导师展示实力都靠这里。

## 为什么要做作品集？

考研复试面试官看的不只是成绩单，**能拿出来跑的作品才是硬通货**。
药学 + Python 的交叉方向（计算药学、生物信息、药物设计）尤其看重动手能力。

## 目录规划

```
作品集/
├── README.md              # 本文件（作品集总览）
├── 项目1-XXX/             # 每个项目一个文件夹
│   ├── 项目说明.md        # 做什么、为什么、用了什么技术
│   ├── 代码文件.py/.ipynb
│   ├── 数据/              # 输入数据
│   └── 结果/              # 输出图表、报告
├── 项目2-XXX/
└── ...
```

## 建议的项目方向（按难度递进）

### 第 1 档：课程完成型（基础）
- 某章综合测验的完整解答 + 笔记整理
- 展示：编程基本功扎实

### 第 2 档：数据处理型（推荐先做）
- 实验数据批量处理脚本（读取 Excel → 清洗 → 统计 → 出图）
- 标准曲线自动拟合（线性回归）
- 展示：会用 pandas/numpy/matplotlib/scipy

### 第 3 档：药学专业型（你的主场）
- RDKit 分子描述符计算 + 类药性筛选
- QSAR 模型（分子指纹 + 机器学习预测活性）
- 化合物相似性检索
- 展示：化学信息学 + 机器学习

### 第 4 档：研究课题型（高年级）
- 结合自己课题的完整分析（如分子对接结果分析、药效数据挖掘）
- 展示：独立完成科研数据分析的能力

## 每个项目的说明文档要写什么

```markdown
# 项目名称
## 1. 项目背景（为什么做这个）
## 2. 数据来源与说明
## 3. 方法/技术栈（用了哪些库、哪些算法）
## 4. 结果与图表（放图！）
## 5. 结论与心得（学到了什么）
```

面试官 3 分钟能看完你的项目说明，所以**图比字重要，结论比过程重要**。
