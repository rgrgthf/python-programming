## 环境说明

- 基础学习：系统 Python 3.14（VS Code 默认）
- 科研计算：conda 环境 `sci`（Python 3.12，含 pandas/numpy/scipy/rdkit/sklearn/biopython）
- 第 18 章（pandas）以后请切换到 sci 环境运行
- 需另装：openpyxl（Excel）、pytest、requests、beautifulsoup4、flask、torch（学到时再装）

## 学习节奏（我的方法）

1. 阅读章节笔记（注释+代码一起看）
2. 动手运行、修改代码
3. 完成阶段测验
4. 严格批改 → 错题进重做练习册
5. 不定期综合测验查漏补缺
